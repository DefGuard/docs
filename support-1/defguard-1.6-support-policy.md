# Defguard 1.6 Support Policy

### Overview

With the release of newer Defguard versions, version **1.6** enters the maintenance phase of its lifecycle. This page describes what kind of support you can expect for Defguard 1.6 and for how long.

### Support timeline

Defguard 1.6 will be supported until the **end of October 2026**.

After this date, version 1.6 will reach End of Life (EOL) and will no longer receive any updates, including security fixes. We strongly recommend planning your upgrade to the latest Defguard version well before the EOL date.

### What is included in 1.6 support

During the maintenance period, Defguard 1.6 will receive:

* **Security fixes** — patches for important security vulnerabilities affecting the 1.6 release line.
* **Critical bug fixes** — fixes for critical issues (blockers) that prevent core functionality from working, with no reasonable workaround available.

### What is not included

The following will **not** be backported to the 1.6 release line:

* New features and enhancements
* Non-critical bug fixes
* Performance improvements
* UI/UX changes

All new development takes place in the current release line.

### Recommendations

* If you are running Defguard 1.6, you can continue to operate it safely until the end of October 2026, applying maintenance releases as they are published.
* Plan and test your upgrade to the latest version ahead of the EOL date to ensure a smooth transition and uninterrupted access to new features, improvements, and full support.
