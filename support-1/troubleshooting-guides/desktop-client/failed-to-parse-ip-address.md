# Failed to parse IP address

<figure><img src="../../../.gitbook/assets/image (248).png" alt=""><figcaption></figcaption></figure>

This error indicates that the desktop client version is too old to communicate with the current core or Edge services. The client receives a response format it does not understand and fails to parse it.

Update the desktop client to the latest stable release: https://defguard.net/download/

After updating, retry the connection. No additional configuration changes are needed.
