# Mobile client

To view the mobile client logs open the side menu by tapping the menu icon.

<figure><img src="../../.gitbook/assets/F64A30B5-AD40-431A-A72E-467A7EAFDC1F (1).PNG" alt="" width="375"><figcaption></figcaption></figure>

Tap the _View Application Logs_ link from the side menu.

<figure><img src="../../.gitbook/assets/0257A34A-D5E0-4D6D-9627-EA5149B891A1.PNG" alt="" width="375"><figcaption></figcaption></figure>

You will see the application logs. Tap the menu icon again to see possible actions.

<figure><img src="../../.gitbook/assets/93A00C9F-4F80-4B55-8EEE-19A3AB957629.PNG" alt="" width="375"><figcaption></figcaption></figure>

Tap the _Share logs file_ item to sent the log file using a desired app.
