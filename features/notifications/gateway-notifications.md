# Gateway notifications

You can configure automatic e-mail notifications when one of your gateways disconnects.

### Requirements

* SMTP server configured in Defguard (SMTP tab in settings)

### Configuration

In order to configure the notifications, navigate to the "Gateway notifications" settings tab.

<figure><img src="../../.gitbook/assets/image (68).png" alt=""><figcaption></figcaption></figure>

The configuration options are as follows:

* **Enable gateway disconnect notifications** - whether the notifications should be enabled
* **Gateway inactivity time** - the time for which the gateway needs to stay disconnected in order to trigger the notification
* **Enable gateway reconnect notifications** - whether to send the notification when the gateway connects again after
