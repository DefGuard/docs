# Overview

## Welcome to Defguard admin documentation

This documentation walks you through all the administrative features of Defguard and how to configure them.

We recommend having your own Defguard instance set up to explore these features firsthand. As you follow along, you can adjust the configuration directly within your instance to better understand each feature in action.

If you don't have your instance yet, start it easily using our [one-line install script](../getting-started/one-line-install.md).

### What you’ll learn

As a future Defguard administrator, this documentation will help you:

* Be aware of all the possibilities you have with Defguard.
* How to configure them to your needs.
