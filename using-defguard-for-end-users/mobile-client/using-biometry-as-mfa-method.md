# Using Biometry as MFA method

In this guide, you will learn how to use biometry as MFA method when connecting to VPN location.

### Setting up Biometry

{% hint style="warning" %}
Biometry can be configured during adding Instance. If you skip this step, you will not be able to add biometry later, only removing and adding Instance again will trigger this modal.
{% endhint %}

First, start the process of adding a new Instance ([check this article](instance-adding.md#adding-instance-in-defguard)). You will see this screen.

<figure><img src="../../.gitbook/assets/image (44).png" alt="" width="372"><figcaption></figcaption></figure>

Click **Yes**, after confirming your biometry method, you will see the following screen.

<figure><img src="../../.gitbook/assets/image (45).png" alt="" width="372"><figcaption></figcaption></figure>

Biometry is now configured! It will be available as a method during connection process.
